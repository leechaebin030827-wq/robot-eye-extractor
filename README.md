# 로봇 눈 모션 제작소

눈 감정/동작 에셋을 **블록처럼 이어 붙여** 자연스러운 눈 영상을 만들고 **MP4로 내보내는** 도구.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm test
```

## 사용법
1. 왼쪽 라이브러리(감정 · 동작 · 시선)에서 에셋을 누르면 아래 시퀀스 끝(또는 선택한 블록 뒤)에 블록이 붙습니다.
2. 블록을 드래그해 순서를 바꾸고, 클릭해서 길이를 조절/복제/삭제합니다. (스페이스 = 재생/정지)
3. **연결 부드러움**: 블록 경계에서 감정이 크로스페이드되는 시간(ms).
4. 위쪽에서 **LED 매트릭스**(8×8 두 개, 10 mm 간격) / **자유형 눈**과 눈 색을 고르고, 크기를 정한 뒤 **MP4 내보내기**.

작업 내용은 브라우저에 자동 저장됩니다.

## 자연스러움의 원리
* 감정은 블록 경계에서 보간(크로스페이드), 동작은 시작/끝이 “현재 시선”에서 출발·복귀하도록 설계되어 컷이 튀지 않습니다.
* 시드 기반의 idle 시선 흔들림과 자동 깜빡임이 항상 아래에서 계속 동작합니다 (같은 시간 = 항상 같은 프레임, 영상 재현 가능).
* MP4는 실시간 녹화가 아니라 프레임을 정확한 시각으로 하나씩 그려 H.264로 인코딩(WebCodecs + mp4-muxer)하므로 끊김이 없습니다. 30 fps.

## 구조
```
src/studio/assets.ts     에셋 정의(29개) · 블록 → 타임라인 컴파일
src/studio/draw.ts       한 프레임 그리기 (매트릭스 / 자유형 공용)
src/studio/exportMp4.ts  MP4 인코딩
src/engine, src/render   눈 상태 계산 · 8×8 / 벡터 렌더러
```
MP4 내보내기는 WebCodecs를 지원하는 최신 Chrome / Edge / Safari 필요.
